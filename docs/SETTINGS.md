# 设置中心 / Settings

独立窗口，左侧导航 + 右侧分组卡片。信息架构照用户给的「岛仔设置」截图，内容换成 tot 的。窗口 1080×760，可缩放，深色优先、跟随系统。

## 1. 导航与页面

| 分组 | 页面 | 内容 |

## 2. 存储

`%APPDATA%/EmojiTot/prefs.json`。唯一的结构定义在 `apps/desktop/src/shared/schema.js`：默认值、页面 manifest、状态组件 manifest 与每个键的消费者都写在那一份文件里，主进程读完补默认值，设置页与岛都从同一份表渲染。审计矩阵见 [SETTINGS-AUDIT.md](SETTINGS-AUDIT.md)。

```json
{
  "form": "island",
  "formBoth": false,
  "skin": "frost",
  "blur": true,
  "displayId": null,
  "anchor": "top",
  "islandWidth": 420,
  "avoidTopBar": true,
  "timeFormat": "24h",
  "statusItems": ["battery", "clock", "weather", "quota", "volume"],
  "pages": { "music": true, "weather": true, "quota": true, "mail": true },
  "pageOrder": ["music", "weather", "quota", "mail"],
  "weather": { "city": "香港", "unit": "c" },
  "mail": [],
  "quota": { "provider": "deepseek", "intervalMin": 15 }
}
```

## 3. 交互约定

- 每个开关改动立即写盘并作用于运行中的窗口与服务，不设「保存」按钮，也不需要重启。
- 分组开关（`focus.enabled`、`shelf.clipboard` 这类）写的是嵌套路径；写成字面量键的话读不到，测试会失败。
- 敏感值（邮箱授权码、API key）用 Electron `safeStorage` 加密后存 `secrets.bin`，界面上只显示掩码和「已保存」。
- 空态给一句话 + 一个动作按钮：「还没有添加邮箱 → 添加」。
- 每页标题下不加说明性小作文；一句副标题足够。
