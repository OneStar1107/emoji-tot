# 变更记录

已发布的版本，新的在上。版本号规则见 [RELEASING.md](RELEASING.md)。

## 0.8.20.17

- 暂停恢复按钮的保留时间结束后，暂停音乐不再锁定媒体归属，灵动岛会重新识别正在播放的直播、视频或其他媒体；没有其他媒体时回到空闲状态。
- 原生媒体监听同时携带暂停音乐与最佳备用播放器；超时后由同一媒体选择器切换，播放控制跟随当前显示来源。
- 恢复按钮悬停或键盘聚焦仍会同时续期界面与主进程计时，音乐重新播放时立即恢复音乐优先。
- 修复没有备用媒体时读取空值导致主进程弹错的问题，并增加对应回归测试。

## 0.8.20.16

- 暂停恢复按钮的保留时间新增 1 分钟选项，可选永不隐藏、1、15、30、60、120 分钟。
- 默认空闲隐藏时间由 30 分钟调整为 15 分钟。

## 0.8.20.15

- 音乐从播放变为暂停时，收起胶囊立即回到时间、电量等状态行，展开页同时折叠；暂停歌词与标题不再占据岛面。
- 胶囊右侧新增固定槽位的封面播放按钮，直接恢复当前暂停歌曲；再次展开先显示常规页面，不自动回到暂停歌词页。
- 恢复按钮新增可配置的空闲隐藏时间：默认 30 分钟，可选永不隐藏、15、30、60、120 分钟；悬停或键盘聚焦会重新计时。

## 0.8.20.14

- 收起胶囊在媒体暂停时继续显示当前歌曲标题和歌手，不再切回电量、时间状态行；音乐和直播同时存在时，展开页与收起胶囊都保持音乐，恢复播放仍控制同一播放器。
- 修复哔哩哔哩直播会话错误报告为音乐时抢占暂停中网易云的问题；直播证据优先于误导性的播放类型，音乐会话存在期间封面、进度、来源和控制归属保持一致。
- 修复 Windows PowerShell 5 将无 BOM 脚本中的中文直播关键词按 ANSI 读取的问题，并统一媒体 JSON 输出为 UTF-8。

## 0.8.20.13

- 修复哔哩哔哩直播会话错误报告 `PlaybackType=Music` 时抢占暂停中网易云音乐的问题：直播证据现在优先于误导性的播放类型，音乐会话存在期间始终显示音乐。
- 修复媒体控制与画面选择不一致：灵动岛的暂停 / 继续 / 上一首 / 下一首继续指向音乐，暂停后从灵动岛恢复音乐，直播不会接管控制。
- 修复 Windows PowerShell 5 将无 BOM 脚本中的中文直播关键词按 ANSI 读取的问题，并统一媒体 JSON 输出为 UTF-8；新增真实会话优先级和脚本兼容性回归测试。

## 0.8.20.12

- 修复音乐暂停后被同时播放的直播接管、重新播放后仍无法从灵动岛控制音乐的问题：媒体选择和控制命令现在都优先保留音乐会话，直播只在音乐会话关闭后回退显示。

## 0.8.20.10

- 媒体页从 217px 扩展到 260px，按参考图改为左侧 96px 封面、右侧歌词卡片和下方独立控制条；进度条、当前时间 / 总时长与来源放在歌词卡片底部，页面和分页按钮在所有岛页之间保持同一高度。
- 收起胶囊恢复同步歌词显示：第一行是当前歌词，第二行是“歌名 - 歌手”，歌词尚未到达时回退到歌名；展开页和收起态共用同一切句时钟。
- 收起态歌词使用固定文字槽和省略号，歌词切句只原位更新文本，不调用胶囊重绘或重新测宽；当前歌词、上一句和下一句都保留，当前句最多两行。
- 布局与固定歌词窗设计参考了 MIT 开源的 `Fuwni/dynamic-island-windows`、`shirkeharsh/mooziac` 和 `devcode90/Dynamic-Island-for-Windows` 的公开实现；这些项目分别使用 WPF、Swift 与 C++，本仓库没有复制其源码。

## 0.8.20.9

- 展开媒体页删除封面右侧的重复歌名，只保留灵动岛顶栏标题；歌词列扩大为 17px 的上一句、当前句、下一句，当前句最多两行。
- 收起胶囊改为固定宽度的“歌名 - 歌手”文字槽，长标题右端省略；歌词换句不再重绘或测量胶囊，因而不会播放中反复伸缩和跳动。
- 媒体分类统一为音乐、有限时长视频/播客/普通媒体、直播和未知媒体，并按该顺序仲裁；音乐暂停、停止或退出后才让直播接管，避免标题来自音乐而封面来自直播。
- 网易云回退帧缺少封面时，按精确歌曲 ID 查询 200px 专辑图，使用受域名白名单、超时与体积限制保护的下载，并缓存成功或失败结果。实现参考 MIT 开源的 `alent17/Wind0ws_Dynamic_island`，完整许可随模块保留。

## 0.8.20.8

- 修复部分网易云歌曲在客户端内有歌词、灵动岛却提示“没有同步歌词”的问题：网易云会话现在优先按歌曲 ID 查询网易云歌词目录，缺少 ID 时按歌名、歌手和时长搜索，失败后才回退 LRCLIB。
- 歌词切句不再等待每秒一次的媒体采样：界面根据最近一次采样时间补算播放位置，并在下一句的准确时间点唤醒，收起态和展开态同时减少滚动延迟。
- 切歌时先清掉上一首歌词并显示“正在同步歌词…”，旧请求晚返回也不会覆盖当前歌曲；歌词服务连接失败与歌曲确实没有歌词会显示不同提示。
- 新增网易云精确 ID、搜索匹配、LRC offset、媒体采样外推和下一句调度回归测试。网易云歌词接口事实与歌词时钟策略参考了公开的 NeteaseCloudMusicApi、LRCLIB 与 fly-island 实现，未复制 GPL-3.0 源码。

## 0.8.20.7

- 网易云播放器与灵动岛控制共用同一刷新链路，切歌后的标题、进度、歌词和封面会在下一次采样内同步。
- 网易云任意启动顺序、双向 seek、歌词上下文以及音乐优先于直播的行为保持不变。

## 0.8.20.6

- 网易云音乐时间线在任意启动顺序下都能立即显示，并支持网易云与灵动岛之间的双向 seek；普通音乐和视频使用 Windows 媒体时间线，直播保持不可拖动。

## 0.8.20.5

- 网易云音乐改用 MIT 开源的 elog 解析状态机作为首选时间源，精确读取歌曲、真实总时长、播放/暂停和外部点击/拖动后的新位置；`webdb.dat` 只在缺少元数据时补歌名歌手。

- 播放位置变化会立即重算歌词索引，因此无论从网易云还是灵动岛拖动，进度、时间和歌词都会在同一个画面更新；直播仍不提供 seek。
