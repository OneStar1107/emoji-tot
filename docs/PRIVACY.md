# 隐私与数据保留

这份文档回答三个问题：本机存了什么、存多久、怎么删。它不是承诺，是对 apps/desktop/src/main 里真实代码的描述；改代码时请一起改这里。

## 一句话

**没有账号，没有遥测，没有云同步。** 应用只访问三类外部服务：天气（Open-Meteo）、歌词（LRCLIB）、你自己配置的邮箱与日历订阅。除此之外不发出任何请求。

## 存在哪

均在 app.getPath("userData") 下，Windows 上是 %APPDATA%\EmojiTot\。**应用只发布 Windows 版**：除电量外，所有平台能力都依赖 PowerShell，macOS 打包目标已移除。

| 文件 | 内容 | 加密 | 保留 |
| --- | --- | --- | --- |
| prefs.json | 设置与界面状态 | 否 | 直到你删除 |
| state.json | 当前表情，供其它工具读写 | 否 | 持续覆盖 |
| secrets.bin | 邮箱授权码、AI API Key | **是**（safeStorage） | 直到你删除账号 |
| cache-calendar.json | 日程事件与订阅列表 | 事件否；**订阅 URL 是** | 30 分钟刷新一轮，持续覆盖 |
| cache-weather.json | 天气读数与城市 | 否 | 持续覆盖 |
| cache-health.json / focus.json / todos.json | 计时与待办 | 否 | 直到你删除条目 |
| clipboard.json | 剪贴板历史（**默认关闭**） | 否 | 7 天，最多 60 条 |
| shelf/ | 你拖进置物架的文件副本 | 否 | 直到你删除 |
| mail-cache.json | 最近 10 封邮件的发件人、主题、时间 | 否 | 每次同步覆盖 |

### 为什么有的能加密、有的不能

safeStorage 只在用户已登录且有可用系统钥匙串时可用（Windows 走 DPAPI）。它适合**短凭证**：邮箱授权码、API Key、日历订阅 URL。

不适合加密的是需要被人类直接阅读、或需要被其它程序当普通文本读的东西：prefs.json、todos.json、shelf/ 里的文件、state.json。加密这些只会让「打开数据目录看看」这件事失效，而不减少任何实际风险——它们跟你的文档在同一块盘上，磁盘加密（BitLocker / FileVault）才是这一层该用的工具。

secrets.bin 里每条都带前缀：v1: 是 safeStorage 加密后的结果，plain: 表示系统钥匙串不可用时的明文回退。**看到 plain: 就说明这台机器没有可用的钥匙串，凭证是明文存的**——这是刻意的可见设计，不是静默降级。

## 剪贴板历史

默认**关闭**。

- 打开后每 1.5 秒读一次系统剪贴板，只保留纯文本，跳过空内容与超过 8000 字的条目。
- 最多 60 条，7 天后自动丢弃未被固定的条目。
- **关闭开关立即清空所有未固定条目。** 固定（置顶）的条目会保留——那是你手动标记的收藏，所以设置里另有一个「清除全部记录」按钮，删除包括固定项在内的全部内容。
- Windows 上密码管理器会用「禁止监视」剪贴板标记防止被抓取，但 Electron 读不到这个标记，所以这里没有基于内容类型的过滤。**不要把密码管理器里的内容手工复制两遍**——那会绕过标记。

## 消息未读

只读窗口标题，不读聊天内容。标题里没有条数的应用（QQ NT）只报「运行中」。没有任何一个消息应用的内容被写盘。

## 日历解析支持范围

订阅与邮件邀请都走同一个 ICS 解析器（apps/desktop/src/main/ics.js）。**支持**：

- 时间形式：UTC（结尾 Z）、本地无时区、`TZID=` 命名时区、`VALUE=DATE` 全天事件。
- 文本转义：`\,` `\;` `\n` `\\`，以及跨行折叠（续行以空格或制表符开头）。
- 重复规则：`FREQ=DAILY|WEEKLY|MONTHLY|YEARLY`，配 `INTERVAL`、`COUNT`、`UNTIL`，最多展开 30 次。
- 身份：`UID` 用于去重，去重键是 UID + 来源 + 开始时间。

**不支持的字段**（遇到时只显示该条基础事件，不做猜测性展开）：`BYDAY`、`BYMONTHDAY`、`BYYEARDAY`、`BYWEEKNO`、`BYSETPOS`、`BYHOUR`、`BYMINUTE`、`BYSECOND`、`BYMONTH`，以及 `EXDATE`（排除日期）、`RDATE`（额外日期）、`RECURRENCE-ID`（单次改期覆盖）。

后三类是共享日历里最常见的「某一次被改了时间」场景：目前那次改动会被忽略，事件仍按原始规则显示。宁可显示一条确定存在的，也不显示一条猜出来的。

## 删除

| 想删什么 | 怎么做 |
| --- | --- |
| 剪贴板历史 | 设置 → 待办与置物 → 清除全部记录 |
| 单个待办 / 日程 / 邮箱账号 / AI 账号 | 设置里对应列表的删除按钮 |
| 置物架文件 | 设置 → 关于 → 打开数据目录 → 删 shelf/ |
| 全部数据 | 关闭应用，删除整个 %APPDATA%\EmojiTot\ 目录 |

卸载安装版默认**保留**数据目录（跟多数桌面应用一致）；要彻底清除就是上面最后一行。

## 网络

| 目标 | 何时 | 送出去的东西 |
| --- | --- | --- |
| api.open-meteo.com | 天气刷新（默认 15 分钟） | 城市名或 IP 位置、单位 |
| geocoding-api.open-meteo.com | 城市名解析 | 城市名 |
| lrclib.net | 换歌时 | 歌名、艺人、时长 |
| ipapi.co / ipinfo.io | 开启自动定位时 | 你的出口 IP |
| 你的 IMAP 服务器 | 每 5 分钟 | 登录凭证（走系统钥匙串） |
| 你的 AI 服务商 | 刷新余额时 | API Key |
| 你的日历订阅链接 | 每 30 分钟 | —（URL 本身含 token） |

主进程绕过系统代理直连（session.setProxy({ mode: "direct" })）：这几个域名的证书验证由 Chromium 完成，跳过代理是为了避免一个没启动的代理让所有请求挂起。

## 遥测

**没有。** 应用不发送崩溃报告、使用统计或版本心跳。更新靠手动下载安装包。
