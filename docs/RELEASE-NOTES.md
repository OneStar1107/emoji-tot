# Release notes

SemVer 规则见 docs/RELEASING.md。MINOR 及以上必须在本文件中列出至少 3 条用户可感知的改动。

> 面向用户的完整历史见 [CHANGELOG.md](CHANGELOG.md)（README 只引用那一份）；本文件保留 0.6.0 起的逐版详细条目，`pnpm version:check` 读这里。

## 0.8.20.17

- **保留时间结束后重新识别媒体**：暂停音乐的恢复按钮到时隐藏后，暂停会话不再一直占据灵动岛；正在播放的直播、视频或其他媒体会自然接管。
- **控制跟随当前画面**：切换到直播或其他媒体后，播放、上一首、下一首和进度命令会指向当前显示来源，不再误发回已经超时的暂停音乐。
- **音乐恢复仍即时夺回**：只要暂停音乐重新播放，音乐优先级立即恢复；鼠标悬停或键盘聚焦恢复按钮仍会续期，避免操作时突然切走。
- **没有备用媒体时安静回到空闲**：暂停音乐超时且没有直播或视频可接管时，只显示正常的空闲状态，不会因缺少备用会话弹出主进程错误。

## 0.8.20.16

- **恢复按钮新增 1 分钟选项**：“音乐与歌词 → 暂停后的灵动岛 → 恢复按钮保留时间”现在可选择永不隐藏、1、15、30、60 或 120 分钟。
- **默认空闲隐藏时间改为 15 分钟**：暂停后的小播放按钮会更早退出状态胶囊，减少长时间闲置时的视觉占用。
- **操作恢复按钮会重新计时**：鼠标移到按钮上或键盘聚焦时刷新空闲倒计时，移开后重新按所选时长计算，不会在正在操作时突然消失。

## 0.8.20.15

- **暂停音乐立即把灵动岛还给状态信息**：从网易云、系统媒体键或灵动岛暂停时，展开页自动收起，胶囊马上显示时间、电量、温度等状态，不再让暂停歌词占着岛面。
- **胶囊保留一个可直接继续播放的小按钮**：固定宽度槽位显示当前封面与播放符号，点击即可恢复暂停的歌曲，不需要打开播放器或先进入媒体页；再次展开也先回到常规页面。
- **恢复按钮支持空闲自动隐藏**：默认暂停 30 分钟后隐藏，可在“音乐与歌词 → 暂停后的灵动岛”选择永不隐藏、15、30、60 或 120 分钟。鼠标或键盘操作按钮会重新计时。

## 0.8.20.14

- **暂停后收起胶囊也继续显示音乐**：只要媒体会话还存在，暂停中的歌曲标题和歌手不会再被电量、时间等状态行替换；展开页与收起胶囊始终显示同一首音乐，恢复播放仍使用同一个播放键。
- **直播不再抢走暂停中的音乐**：哔哩哔哩会话即使错误报告为音乐类型，也会按直播证据识别；只要网易云会话仍存在，封面、进度、来源和播放控制都保持属于音乐。
- **中文直播来源在 Windows PowerShell 5 下也能正确识别**：直播关键词不再受脚本编码影响，媒体 JSON 统一使用 UTF-8，避免来源判断失效或中文标题乱码。

## 0.8.20.13

- **暂停音乐不会再被直播顶掉**：修复哔哩哔哩会话误报为音乐、却因正在播放而抢走画面的情况；只要网易云音乐会话仍存在，灵动岛和展开页都持续显示歌曲、封面和进度。
- **播放控制始终回到音乐**：音乐与直播同时播放时，灵动岛暂停、继续、上一首和下一首始终作用于音乐；从暂停恢复后会立即继续控制网易云，不需要先关闭直播。
- **媒体标题和来源判断不再受编码影响**：Windows PowerShell 5 下也能正确识别“哔哩哔哩 / 斗鱼 / 直播”等中文证据，避免直播被当成音乐，同时保持中文标题正常传输。

## 0.8.20.12

- **音乐暂停后不再被直播顶掉**：只要音乐播放器仍有媒体会话，灵动岛就保持显示歌曲和播放键；暂停时可以重新播放，直播只在音乐会话真正关闭后才接管。
- **播放控制始终属于音乐**：灵动岛的暂停、继续、上一首和下一首命令与画面选择使用同一优先级，不会再误发给正在播放的直播。
- **重新播放会立即回到歌曲**：从播放器或灵动岛恢复音乐后，曲名、封面、进度和歌词继续显示音乐，不需要关闭直播或重新打开 EmojiTot。

## 0.8.20.10

- **媒体页按参考图重新分层**：页面向下扩展到 `260px`，左侧封面和右侧歌词卡片共享这块更大的区域，进度、时间与来源收进歌词卡片底部，播放控制独立成下方控制条；所有岛页仍使用同一高度，翻页时窗口不会跳动。
- **收起状态也显示同步歌词**：第一行显示当前歌词，第二行显示“歌名 - 歌手”，未取到歌词时自动回退到歌名；收起态和展开态使用同一播放位置切句，不再只是一个静止标题。
- **歌词变化不再撑动灵动岛**：两行文字始终位于固定槽内，长句以省略号收口；切句只替换文字节点，不重新测量胶囊，因此长歌词、短歌词和换句都不会让岛反复伸缩。当前句仍最多两行，并保留上一句、下一句作为上下文。

## 0.8.20.9

- **媒体页去掉重复歌名，歌词更好读**：歌名只留在灵动岛顶栏；封面右侧改为 17px 的上一句 / 当前句 / 下一句，当前长句仍最多两行。
- **收起胶囊不再随歌词跳舞**：播放时固定显示“歌名 - 歌手”，使用固定文字槽和省略号；歌词只在展开页滚动，不再因为每句长短不同反复改变胶囊宽度。
- **音乐、视频与直播只显示同一条完整媒体**：优先级统一为音乐 > 有限时长视频/播客/普通媒体 > 直播 > 未知媒体；音乐播放时封面、标题、进度和歌词都来自音乐，音乐暂停后才切回直播。
- **补齐网易云缺失封面**：当系统会话只给直播、网易云由本地日志回退提供时，按精确歌曲 ID 获取 200px 专辑封面并缓存；只接受网易云 CDN 地址，并限制重定向、超时和下载体积。封面查询借鉴 MIT 开源的 `alent17/Wind0ws_Dynamic_island`，许可声明随程序保留。

## 0.8.20.8

- **网易云里有歌词，灵动岛也会显示**：网易云播放时先按歌曲 ID 读取网易云自己的同步歌词；没有 ID 时再用歌名、歌手和时长匹配。LRCLIB 现在是后备数据源，不再因为那里没有收录就误报“这首歌没有同步歌词”。
- **歌词滚动延迟压到切句时刻**：不再等下一次一秒媒体采样，EmojiTot 会在两次采样之间补算真实播放位置，并按下一句的时间点精确唤醒。收起胶囊和展开歌词页都会更贴近歌手实际唱到的那一句。
- **切歌不再短暂沿用上一首歌词**：新歌先显示“正在同步歌词…”，旧请求即使晚返回也不会覆盖当前歌曲；网络失败会明确显示连接失败，而不是把服务问题说成歌曲没有歌词。

## 0.8.20.7

- **切歌后的封面不再停留在上一首**：Windows 有时先更新网易云歌名、稍后才更新 SMTC 缩略图；EmojiTot 现在会在新曲目开始后持续检查封面，不再读到一次旧图就缓存整首歌。
- **网易云和灵动岛的上一首 / 下一首都会刷新封面**：两条控制路径最终共用同一媒体时间线，切歌后标题、进度、歌词和封面会在短暂采样间隔内一起落到新曲目。
- **原有播放同步保持**：网易云任意启动顺序、双向拖动进度、音乐优先于直播，以及上一句 / 当前句 / 下一句的歌词同步均继续生效。

## 0.8.20.6

- **点击进度条后播放信息不再停住**：分页圆点现在只响应自己的点击，媒体页里的进度、歌词和播放按钮不会再被误当成翻页；无论点击还是拖动进度条，时间、进度和歌词都会继续跟随播放器同步。
- **网易云进度不再依赖启动顺序**：无论先打开 EmojiTot 还是先播放网易云，都会立即显示“当前进度 / 总时长”；网易云到灵动岛、灵动岛到网易云两个方向点击或拖动都会同步，其他音乐和视频也通过 Windows 媒体时间线获得双向 seek。
- **歌词会滚到当前句**：展开页保持上一句、当前句、下一句同时可见，当前长句最多占两行；网易云内部拖动或从灵动岛 seek 后都会立即重算歌词，不再停在开头。
- **同时播放时音乐优先于直播**：音乐运行时不会被直播抢占，音乐暂停、停止或退出后再切回直播；实现复用并保留了 `YouRanCoder/netease-cloudmusic-detector-py` 与 `alent17/Wind0ws_Dynamic_island` 两个 MIT 项目的许可声明。

## 0.8.20.5

- **网易云进度是真的，不再靠猜**：改用 MIT 开源项目验证过的本地日志解析方式，直接取得歌曲、真实总时长、播放/暂停和拖动后的精确位置；原来的历史数据库只负责补歌名、歌手和专辑。
- **两个方向拖动都会同步**：在网易云点进度条或拖动，灵动岛会立刻重锚时间并更新歌词；在灵动岛拖动，成功后再把网易云的新位置读回来，不会跳回旧进度。其他音乐软件和视频也改用更快的媒体会话采样。
- **音乐优先于直播**：音乐和直播同时播放时只显示音乐；音乐暂停、停止或退出后自动显示直播，符合一次只听一路声音的使用习惯。
- **长歌词保持上句 / 当前句 / 下句**：当前句最多显示两行，仍在中间突出显示；上一句和下一句各占一行，不会为了完整长句把上下文挤出画面。

## 0.8.20.4

- **网易云音乐的进度和歌词会真正跟上了**：部分网易云版本只向 Windows 提供歌名和封面，不提供可用的播放时间线，导致媒体页一直停在 `00:00 / --:--`，歌词也无法滚动。现在 EmojiTot 会在系统媒体会话缺少时间线时，只读取网易云本地最近播放记录中的歌名、歌手、总时长和播放起点，并用系统音频会话同步播放/暂停；其他播放器仍优先使用 Windows 媒体会话。
- **不再依赖两个应用的启动先后**：先打开 EmojiTot、后播放网易云，或先播放网易云、后打开 EmojiTot，都会在首次采样后显示当前位置与总时长；切歌会立即重置，歌词按同一播放位置更新。
- **播放操作和来源显示保持原样**：网易云仍显示“网易云音乐”来源，系统提供的封面不会被本地回退覆盖；从 EmojiTot 暂停后会冻结进度，恢复后从同一位置继续。

## 0.8.20.1

- **AI 工作台的状态现在是真状态**：不再把启用监听当成“会话”，过期状态文件也不会一直显示“运行”。应用会分别检查 DeepSeek Harness、Claude Code、Codex 是否真的打开；启动中的平台排在最前，多个平台同时启动时任务多者优先，任务数相同则保持原顺序。
- **AI 工作台更紧凑且滚动不冲突**：余额区缩小，右侧滚动条移除但滚轮滚动保留；鼠标在下半区时只滚动 Agent 内容，移到区域外才切换上下页面。
- **歌词链路修好并同步到灵动岛**：修复 LRCLIB 请求地址丢失的问题，并增加模糊搜索、乐器判断和时长容差；收起态显示当前同步歌词，展开页随播放秒数逐行更新，取不到同步歌词时才回退歌名。
- **升级保留本机个人数据**：安装包仍只包含程序文件，账号密钥、偏好、置物架、待办、专注与缓存继续保存在 `%APPDATA%\EmojiTot`，覆盖安装不会清空或上传这些内容。

## 0.8.19.3

- **角色动起来用的是真实状态机**：桌面球、灵动岛、设置预览、引导页和网页四页共用一个 61 状态的角色运行时；弹簧姿态、多边形眼睛、眨眼、视线和一次性动作会从中断点继续，不再只是替换一张 SVG 静态脸。
- **控制台、表情馆、场景和文档统一升级**：四页现在共享同一套状态色、角色检测面板、动作词汇和项目结构说明；控制台所有可见按钮、抽屉、复制、暂停、尺寸与材质选项都已逐项点击并通过回归测试。
- **61 个表情都有中文名**：表情选择器从 51 个协议表情扩展到全部 61 个可绘制状态，补齐 10 个引擎独有状态；深色、浅色、强制颜色、移动端布局和低动态偏好均通过可读性与溢出检查。
- **安装包改为本机自签名**：主程序、卸载器、安装包和最终便携版统一使用 `CN=OneStar1107, O=EmojiTot, C=CN` 自签；本机签名验证为 `Valid`。自签名不建立 SmartScreen 信誉，其他电脑首次运行仍可能提示“未知发布者”，可点“仍要运行”。

## 0.8.18.28

- **状态组件严格居中对齐**：颜文字现在与电量、天气、余额使用同一行盒高度和垂直中心，不会再因字体基线不同而上下错位。

## 0.8.18.27

- **媒体页更简洁**：移除不需要的“更多播放控制”菜单，上一首、播放/暂停、下一首、歌词设置与系统音量保持不变。
- **设置预览回到卡片中央**：页面管理里的常驻胶囊不再偏左，与下方状态组件形成同一条视觉中线。
- **修复站点四页交互**：控制台英文模式的岛内角色名、表情馆灯箱键盘焦点、场景重置后的来源显示，以及文档协议分组的中英文切换现在保持一致。

## 0.8.18.26

- **直播信息显示主播昵称**：直播内容的第二段现在显示主播名，而不是数字 UID；顶部标题、媒体页和收起胶囊保持一致。

## 0.8.18.25

- **斗鱼和 B 站直播封面恢复稳定显示**：斗鱼会从房间接口取回稳定封面；B 站会跳过播放器给出的 300×300 占位图，改用真实房间封面，不再出现有时有、有时没有。
- **直播时长从主播真实开播时间计算**：进入直播间后直接显示当前开播时长，不再从 EmojiTot 检测到直播的那一刻开始从 0:00 计时。

- **“毛玻璃”改名为 Liquid Glass**：外观页和首次引导使用更准确的材质名，与半透明、高光和折射的视觉语言一致；旧设置和 `frost` 配置继续原样兼容。
- **颜文字改为常驻状态组件**：胶囊不再自动追加颜文字；到“页面管理 → 状态组件 · 常驻胶囊”打开“颜文字”后，它会按所在顺序和电量、时间、温度、余额一起显示，默认关闭，没有真实读数时也不会单独出现。

- **皮肤列表精简为三套**：彻底删除“杂志”和“控制台”，外观页与首次引导只保留“毛玻璃 / 实色 / 极简”；旧配置会自动回到“毛玻璃”。

## 0.8.18.20
