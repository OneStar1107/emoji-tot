# Release notes

SemVer 规则见 docs/RELEASING.md。MINOR 及以上必须在本文件中列出至少 3 条用户可感知的改动。

> 面向用户的完整历史见 [CHANGELOG.md](CHANGELOG.md)（README 只引用那一份）；本文件保留 0.6.0 起的逐版详细条目，`pnpm version:check` 读这里。

## 0.8.17

- 修安装/卸载向导左侧栏里的方块乱码：上一版侧栏位图用 Python 画了中文小字，而渲染时选的是拉丁字体（segoeui），没有中文字形，于是全部变成空心方块。现在侧栏只放图形与英文（EmojiTot / SETUP / UNINSTALL / OneStar1107），不再依赖任何中文字体。
- 这版同时带上 0.8.16 的玻璃统一（胶囊与面板同一层照片）与展开时角色漂移修复。
- 安装与卸载用两张不同的侧栏：卸载页以前复用安装页那张，标题写的是 SETUP，现在有自己的 UNINSTALL。
## 0.8.16

- 设置窗口不再是一块实色板：它是矩形窗口，可以直接吃 Windows 11 的 DWM acrylic，背景改成 0.82 半透明，桌面真的透上来；没有系统模糊的机器退回接近不透明的底，文字不会糊。
- 两个下载文件不再混淆：免安装版改名 EmojiTot.<版本>.portable.exe，安装包仍是 EmojiTot.Setup.<版本>.exe。以前免安装版也叫 EmojiTot.<版本>.exe，下错就会以为「安装过程没有」。
- 安装器加回 EmojiTot 自己的位图（24 位 BMP，之前用 32 位才失败），流程仍是 NSIS 原生向导。
## 0.8.15

- **收起和展开现在是同一块毛玻璃**：以前胶囊是 90% 实色卡片、面板才是「桌面的照片 + 64% 色调」，两个状态看起来是两种材质。现在整窗只有一层桌面照片（模糊 + 去饱和 + 压暗），胶囊和面板都只叠一层 64% 的色调，位置完全相同，所以缩放前后是同一块玻璃在变大变小。
- 色调比上一版再透一点（66% → 64%）；再往下压会跌破白底 4.5:1 的文字对比度，所以停在这里。
- **缩放时角色不再漂移**：面板的逆缩放层原来绕自己的中心转，而面板绕顶边中点转，两个原点不一致，整个展开过程中角色会被推着往上滑。现在逆缩放层也绕顶边中点转，两段变换正好抵消，角色从第一帧到最后都不动。
- 自绘安装界面彻底删掉了（位图、配置、文档引用一起清理），安装器只用 NSIS 默认的蓝色向导。

## 0.8.14

- **安装器改回标准向导**：双击就有界面，能选目录、能看到进度、装完可以直接启动。之前那套自绘页面与自定义位图会在部分机器上让安装过程卡住或根本没有反应，已经全部撤掉，用回 electron-builder 自己的流程。
- **装到哪里不再由我指定**：之前默认强塞 `D:\EmojiTot` 的设定删了，现在跟随系统默认（当前用户目录），向导里可以自己改。
- **真毛玻璃回来了，而且是唯一的那层毛玻璃**：系统模糊（Windows 11 22H2 起）重新成为材质本体；设置里那个「截图毛玻璃（兜底）」开关删掉，不再让用户在两种毛玻璃之间二选一。窗口区域改用物理像素计算，150% 缩放下不再把胶囊裁成一条。
- 许可页写明商用联系邮箱 hyx110702@163.com。

## 0.8.13

- **修掉装完之后什么都用不了**：上一版的预加载脚本丢了一个内部函数，界面在启动时就崩了，所以媒体识别不到、天气不出数、设备页空着、胶囊只剩一个干数字。现在全部恢复。
- 蓝牙设备默认显示在岛上（之前这个页面默认是关的，看着像没检测到硬件）。
- 系统毛玻璃那个材质撤了：它会把整块窗口矩形都糊上，圆角外面还是灰的，看着像一块不透明的板；回到原来的分层材质。
## 0.8.12

- **真毛玻璃终于是「默认」的那个毛玻璃**：Windows 11 上窗口由系统自己模糊，面板只负责一层薄薄的色调，桌面和壁纸会真的透过来。以前那种「开一个开关才叫真毛玻璃」的说法没了——系统有模糊就用系统模糊。
- **第一帧就是对的**：材质在页面画之前就定了，不再先画一层 CSS 模糊、等主进程回话再撤掉，所以启动时不会闪。
- 卡片底色更透（深色 0.90 → 0.72、浅色 0.92 → 0.80），只在系统模糊真的生效时降；没有系统模糊的机器维持原样，字不会变糊。
- 设置里的开关改名「截图毛玻璃（兜底）」并写清适用机器：Windows 10 才需要它，打开时会闪一下。
## 0.8.11

- **安装器重做**：从「一键静默」改成向导式——许可证页（显示本项目的非商用协议）、安装目录可选、完成页可直接启动；顶横幅与左侧栏换成项目自己的配色与角色。
- **代码签名方案落地**：新增 `docs/SIGNING.md`，三条路（Azure Trusted Signing / OVF 证书 / 自签名）都写清了怎么配、怎么验。**当前没有证书，安装包仍未签名**——首次运行仍会有 SmartScreen 提示。
- 卸载器共用同一套侧栏视觉；快捷方式名称统一为 EmojiTot，卸载默认保留用户数据（装回去还是原来的角色和偏好）。
## 0.8.10

- **许可证改成不可商用**：源码公开、个人随便用，但不许打包卖钱、放进收费产品或做成带广告的服务；不授予服务商标使用权。README 补了徽章（版本 / 平台 / 许可 / 技术栈）与完整的开源说明。
- **P2 八条一次清完**：天气页空值保护与缓存版本闸门、关闭动画不再反向过冲 5px、形变 rAF 加了超时兜底、玻璃开关文案与矛盾注释、删掉四个入库的 `.orig` 备份、删掉 21 行死代码、置顶上限改为引用 schema、设备顺序改走窄通道（不再整组覆盖）。
- 系统材质下的窗口形状改为静止后重建一次（拖动/形变期间每帧重建会拖慢材质的响应）。
## 0.8.9

- **真毛玻璃，系统自己画**：Windows 11 的 DWM acrylic 直接模糊窗口后面的东西——不抓屏、不排除自己、不每秒重算滤镜。配合 `setShape` 把窗口裁成圆角，四角不会漏出模糊矩形。
- Windows 10 与更早的系统自动退回原来的分层材质（按 build 号判断，不看主版本号）。
- 抓屏那条路保留为可选（设置 → 外观），默认关闭。
## 0.8.8

- 全量自检：单元测试 384 项全绿、窗口冒烟 7/7、站点 browser-check 20/20、敏感信息扫描 PASS。
- 站点与 README 细节跟随修正。
