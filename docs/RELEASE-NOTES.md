# Release notes

SemVer 规则见 docs/RELEASING.md。MINOR 及以上必须在本文件中列出至少 3 条用户可感知的改动。

> 面向用户的完整历史见 [CHANGELOG.md](CHANGELOG.md)（README 只引用那一份）；本文件保留 0.6.0 起的逐版详细条目，`pnpm version:check` 读这里。

## 0.8.7

- 修掉毛玻璃的闪烁与卡顿：抓屏那条路在部分 Windows / 显卡组合下会让窗口一黑一透、字突然高亮，现在**默认关闭**（设置 → 外观里可开），并且形变的那 400ms 不再重算模糊，展开实测 165fps。
- 站点四页全部重设计：控制台把角色画进「路径轨道」并标出 15 角色 / 61 表情 / **0 张图片**；表情馆改成有大小层次的贴纸墙与玻璃灯箱；场景把多会话仲裁演成舞台；文档加了编号目录与可折叠协议表。
- README 从 313 行瘦身到 93 行，历史版本记录搬到 `docs/CHANGELOG.md`（30 个版本），架构取舍另立 `docs/ARCHITECTURE.md`；GitHub About 的简介与 topics 一并更新。
## 0.8.6

- 修掉毛玻璃的卡顿与闪烁：抓屏时把岛自身排除在画面外（之前玻璃里映着面板自己，所以会一黑一透、字突然高亮），画面同时降到 1280 长边，展开实测 158fps。
- 天气地名不再被截掉「区」字：字号降半档，下拉箭头单独占一列。
- 形变动效换成 Apple 的弹簧（stiffness 520 / damping 32，约 4.5% 过冲后回弹），展开与收起都有那一下「弹回」，不再是纯减速曲线。

## 0.8.5

- 天气定位精确到区：反地理编码保留市辖区（adminLevel 6），在番禺区就显示「番禺区」，城市名退到副标题「阴 · 广州 · 中国」。
- 反查服务加了 15 秒超时与一次重试，连续实测稳定拿到区名。
- IP 兜底仍只到城市（国内 IP 库没有区级数据），这时副标题自然只显示城市，不会编造一个区。

## 0.8.4

- 设置 → 设备页的每一行左侧多了拖动手柄，按住即可上下拖动，重新安排外设在岛上的显示顺序。
- 拖出来的顺序会保存，岛上设备页立即按新顺序排列；置顶的设备依然排在最前，置顶内部也按拖动的先后。
- 拖过之后列表下方出现「恢复默认顺序」，一键回到探测顺序。

## 0.8.3

- 站点四页换成一套设计系统：8px 网格、固定字号梯度、三层圆角、一条缓动曲线；背景有顶部主光与细网格，卡片是玻璃 + 细边 + 浅投影。
- 深色成为站点默认（可一键切回浅色），新增 EmojiTot 紫作为唯一强调色。
- 交互补齐：控制台角色眼睛跟随指针、表情网格点选即换；表情馆灯箱大图（Esc / ←→ / 键盘可达）；场景页九张会话卡可点击上报、优先级数字滚动；文档页粘性目录、滚动显现、协议表可折叠并在行尾预览表情。

## 0.8.2

- 真毛玻璃：展开时抓一次当前屏幕，模糊后作为面板背景，透出来的是真实桌面而不是纯色；设置 → 外观里的「真毛玻璃」可以关，截图只留在本机内存。
- 分层玻璃材质：顶部主光、上部柔光与 1.4% 噪点颗粒，配双层内高光（顶部亮线 / 底部暗边）和收敛的环境阴影。
- 收起态胶囊同步换成同一套材质，hover 抬起 1px；抓屏失败时无缝回退到原来的渐变材质。

## 0.8.1

- 收起态的胶囊显示状态组件：脸 + 你启用的电量/时间/温度/余额，按设置顺序排列，宽度随内容自适应（168 → 约 235px），超出上限整项截断；组件全关时才回到颜文字。
- 「页面管理」新增「常驻排列」：还原胶囊外观的预览条，按住组件左右拖动换位（键盘 Alt+←/→），灰色虚线位表示已关闭但保留位置，右上角一键恢复默认。
- 媒体进度条可点可拖：点一下跳、按住拖动松手提交，拖动中不会被每秒推送拽回；直播与无时长禁用。
- 媒体控制补上播放速率、重复、随机（仅在播放器声明支持时出现「⋯」面板），播放器拒绝时按钮禁用并说明。
- 胶囊与设置预览共用同一套读数函数，预览与真胶囊不会说法不一致。

## 0.8.0

- 设置新增「设备」页（内容组）：全部外设一屏列完——类别图标、名称、连接状态与来源、电量条与百分比；每行可隐藏或置顶（最多 3 台），顶部有显示电量总开关、立即重新探测和上次探测时间。岛上的设备页读同一份偏好。
- 启动即探测：开应用约 2 秒出设备清单、5 秒出电量（原来要等 5 分钟的后台周期）；探测从 4 次 PnP 枚举改成一次 CIM 查询，优先发清单再补电量。
- 岛设备列表滚轮只滚自己：指针在列表上滚动不再翻页；列表太短不可滚时仍照常翻页。
- 左栏角色预览去掉圆环：星星、梨、蛋仔不再被圆形裁切。
- 天气默认自动定位：新装首启直接显示所在城市（系统定位优先，未授权按 IP 归属地），手动填城市会关掉自动定位。
- 设置窗口中/英双语：15 页文案全量翻译，常规页切换即刻生效并保留。

## 0.6.5

- 设备电量接入厂商通道（只读）：罗技 HID++、雷蛇、华硕 ROG，以及移植的 18 个品牌族；按 VID/PID 精确匹配，打开页面立即探测、后台每 5 分钟一轮、可手动刷新。
- 蓝牙耳机电量补齐（HFP 节点），西伯利亚 T7 GT 实测读到 100%；修了 MAC 正则误抓 GUID 与 PnP 批量读取上限两个坑。
- 设置页细节：滚动条换成 6px 细条、删掉顶栏搜索框、左栏黑圆改为当前角色的 46px 实时表情预览（与岛/球/颜文字同一 face 源）。
## 0.6.4

- 设备页不再截断：以前只画前 5 台，第 6 台起被「还有 N 台」吞掉（ROG 战刃 3 就排在第七，所以用户看不到）。现在全部渲染、页面内滚动，底部写「共 N 台 · 滚动查看」。
- 蓝牙耳机电量补齐：西伯利亚 T7 GT 的电量挂在免提（HFP）节点上，之前只扫 Bluetooth 类所以读不到；已补扫并按 MAC 对上名字，实测 100%。
- 厂商通道接入（只读）：罗技 HID++、雷蛇、华硕 ROG 三条私有协议首次进入主进程，按需探测——打开设备页立刻查一次（重试 3 次），页面可见 30 秒一轮、离开 5 分钟一次；读不到显示「—」并注明来源，不猜字节。
- PnP 批量读取按 100 分段：一次传 300 多个实例 ID 时系统会静默返回 0 条，之前设备一多就全空。

## 0.6.3

- 天气：真正按位置识别——系统定位（Windows Geolocation，需授权）优先，失败按 ipinfo → ipip → ipapi 回退，HTML/非 JSON 判失败继续；本机实测系统定位给出广州、回退 IP 也给广州；设置里写明「定位只用来决定天气城市，不上传位置、不记录轨迹」。
- 天气页新增 12 小时逐小时条与 4 个常用城市菜单；2×2 小格、6 天条、小时条三者可同屏。
- 媒体页（原「音乐」）：直播时长按秒走，暂停时冻结、恢复继续；断流 ≤30 秒续算、换台归零。B 站直播无系统缩略图，改由公开接口取房间封面，取不到用皮肤色占位。
- 设备页：顶部压缩到 60px，列表从 3 台扩到 5 台；可关电量显示、可置顶最多 3 台；枚举扩到蓝牙 + 2.4G/HID 接收器，读不到电量显示「—」并注明来源。
- 表情：44 → 61 个（对齐参考站的 33 个状态命名）；岛脸、桌面球、颜文字改为单一真相广播，实测 12 次切换 0 次不一致；新增媒体情绪（播放/直播/游戏/暂停/出错/Agent 状态），优先级「手动 > Agent > 媒体 > 空闲」，最短停留 2 秒。
- 日程：可新建、编辑、删除事件；今天最多 2 条 + 「还有 N 件」。
- 专注：今日/本周统计；每 4 个番茄后长休息 15 分钟。
- 待办：高/中/低优先级、每天/每周/工作日重复，完成后立即生成下一条。
- 健康：按本地日期自动归零，最近 7 天迷你柱趋势。
- 置物架：最多 4 组 + 折叠、按名字搜索（Esc 先清搜索再关岛）。
- 视觉修复：天气页页脚被压成 5.56px 造成叠字（改 flex 布局后 11.7px 完整一行）；收起动画「双层文字」14 帧 → 0 帧（内容逆变换 + 提前淡出）。
- 设置页改版：42px 标题栏（搜索 + 主题切换）、左栏 4 组 14 项、行高 44px、危险操作用两次点击确认。

## 0.6.2

- 邮箱大页：每封邮件行内可标已读/未读、可删除（都走真实 IMAP 的 \Seen 与删除），行内两个 28px 键。
- 邮箱支持账户筛选（与「全部/未读」组合过滤），顶部显示「未读 N · 共 M」，可一键把当前筛选全部标为已读。
- 邮箱空态与错误态各一行说明 + 一个动作，贴顶不超过 96px；单账户时不显示账户下拉，避免假选择。
- AI 余额与 Agent 联动合并成一页「AI 工作台」：30px 余额 + 构成条 + 多账号圆点，下面直接是 agent 区块（会话/运行/空闲 + 最多 3 行状态与时长）。
- 两个功能也合并成一套数据：主进程把余额与 agent 合成一个 island:quota-agent 快照，只在变化时推，渲染一层一次重绘。
- 设置里的「Agent 联动」页并入「AI 额度」页（导航 15→14），同一页两组开关用分隔线分组。
- 整体质感一轮：字号收敛到 7 档、页内间距全部落到 4/6/8/10；对比度补到正文 ≥4.5、次要 ≥3（深色毛玻璃下的三级文字与强调色都提亮）；焦点环统一 2px/offset 2；过渡收敛到 120/180/240ms，reduced-motion 归零。

## 0.6.1

- AI 额度页并入了 Agent 联动：余额下面多一行「N 会话 / N 运行 / N 空闲」，点它直接跳到新的「Agent 联动」设置页；没连接时显示「— 未连接」，不编 0。
- 六个板块（音乐、额度、专注、待办、健康、置物架）页首的 12px 空档收到 4px，内容更贴顶。
- 日程页的日历格子点击范围扩到 30×30 以上（视觉大小不变）。
- 设备页的蓝牙行现在能真的打开系统蓝牙设置；媒体开始上报默认输出设备（音乐页封面右上角徽标的数据源）。
- Windows 上邮箱服务其实被平台能力表漏掉而从未启动，已补上并加测试钉住，邮箱页不再是永远空态。
- 展开/收起形变改成单一时钟驱动：任何时刻都能反向（以前收起后 240ms 内点了没反应），冷启动不再硬切，圆角与透明度从当前值续接，曲线与原来逐点重合（轨迹差 ≤1px）。

## 0.6.0

- 新增「消息」页：微信/QQ/飞书/钉钉/企微的会话按应用分组列出，点一行直接切到那个窗口；邮箱页的「消息 N」改成跳转到这一页。
- 设备页升级成电池与设备大页：30px 大电量 + 充电状态 + 4px 分段色条（低于 20 红、低于 50 橙），设备行显示图标/名称/电量条/等宽数字，另有「还有 N 台」。
- 音乐页加歌词模式：点歌词区把歌词铺满整页（当前行 15.5px、上下各两行渐隐），进度条收成 2px 贴底，再点退出；音量面板的数值改成等宽数字。
- 天气请求加一次重试（失败缓存 30 秒）；体检脚本把「多页 0 高」的启动抖动也自动重启一次；机器人不再多出一根悬空天线。
