# Release notes

SemVer 规则见 docs/RELEASING.md。MINOR 及以上必须在本文件中列出至少 3 条用户可感知的改动。

## 0.6.1

- AI 额度页并入了 Agent 联动：余额下面多一行「N 会话 / N 运行 / N 空闲」，点它直接跳到新的「Agent 联动」设置页；没连接时显示「— 未连接」，不编 0。
- 六个板块（音乐、额度、专注、待办、健康、置物架）页首的 12px 空档收到 4px，内容更贴顶。
- 日程页的日历格子点击范围扩到 30×30 以上（视觉大小不变）。
- 设备页的蓝牙行现在能真的打开系统蓝牙设置；媒体开始上报默认输出设备（音乐页封面右上角徽标的数据源）。
- Windows 上邮箱服务其实被平台能力表漏掉而从未启动，已补上并加测试钉住，邮箱页不再是永远空态。
- 展开/收起形变改成单一时钟驱动：任何时刻都能反向（以前收起后 240ms 内点了没反应），冷启动不再硬切，圆角与透明度从当前值续接，曲线与原来逐点重合（轨迹差 ≤1px）。

## 0.6.0

- 新增「消息」页：微信/QQ/飞书/钉钉/企微的会话按应用分组列出，点一行直接切到那个窗口；邮箱页的「消息 N」改成跳转到这一页。
- 设备页升级成电池与设备大页：30px 大电量 + 充电状态 + 4px 分段色条（低于 20 红、低于 50 橙），设备行显示图标/名称/电量条/等宽数字，另有「还有 N 台」。
- 音乐页加歌词模式：点歌词区把歌词铺满整页（当前行 15.5px、上下各两行渐隐），进度条收成 2px 贴底，再点退出；音量面板的数值改成等宽数字。
- 天气请求加一次重试（失败缓存 30 秒）；体检脚本把「多页 0 高」的启动抖动也自动重启一次；机器人不再多出一根悬空天线。
