# Release notes

SemVer 规则见 docs/RELEASING.md。MINOR 及以上必须在本文件中列出至少 3 条用户可感知的改动。

## 0.6.0

- 新增「消息」页：微信/QQ/飞书/钉钉/企微的会话按应用分组列出，点一行直接切到那个窗口；邮箱页的「消息 N」改成跳转到这一页。
- 设备页升级成电池与设备大页：30px 大电量 + 充电状态 + 4px 分段色条（低于 20 红、低于 50 橙），设备行显示图标/名称/电量条/等宽数字，另有「还有 N 台」。
- 音乐页加歌词模式：点歌词区把歌词铺满整页（当前行 15.5px、上下各两行渐隐），进度条收成 2px 贴底，再点退出；音量面板的数值改成等宽数字。
- 天气请求加一次重试（失败缓存 30 秒）；体检脚本把「多页 0 高」的启动抖动也自动重启一次；机器人不再多出一根悬空天线。
